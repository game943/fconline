# FC Online 3D

A browser 3D football game (11v11) built with Three.js. Open `index.html` in a browser to play.

Features: 10 teams, 4 formations, tactics, 4 difficulty levels, day/night/rain, 3 camera modes, passing/through balls/lobs/power shots, tackles and slide tackles, fouls, penalties, corners, throw-ins, goal kicks, goalkeeper AI, stamina, minimap, match stats, sound.

Controls: arrows move, S pass, D shoot, Shift sprint, J pass/tackle, Space or K shoot (hold)/slide, Z or J pass, X or L through ball, I lob, Q switch, E press, C camera, P pause, M mute.
